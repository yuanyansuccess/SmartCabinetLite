六、判定方案说明（已与袁总确认）

开柜前：校验边缘机在线 + 8路摄像头状态（不OK返回主页）

开柜提示页之前先校验边缘机通信状态 + 8路摄像头周期帧状态：二者全部 OK 才放行开柜提示页；任一异常（离线 / 摄像头非 ok）则提示用户并返回功能导航主页（MenuHomePage），本轮借用归还会话不进入开柜环节。 开锁动作由上位机向 IO 板下发开锁指令完成（含开柜调整时的再次开锁，同一通道）。

关柜后：识别结果与库内在库记录比对

不存在"开柜快照"。用户关柜后，上位机收到下位机 IO 口上报的「已关柜」信号，随后向边缘计算机下发识别指令 （recognize_req，接口与出入库一致），边缘机返回全柜实况清单（recognize_ack）。 比对对象是库内在库记录，比对口径：库内在库而柜内没有 = 借用；借出记录对应的工具回到柜内 = 归还；位置与库内登记不符 = 告警（错放）。 借用/归还真实落库分别走 BorrowService::borrowTool / ReturnService::returnTool，并写操作日志；错放超限（第3次仍错放）额外记错误日志。

错放处理（开柜调整）

发现错放后：结果页给出警告提示行，允许用户开柜调整（最多3次）——每次调整向上位机 IO 板下发开锁指令开柜，调整后关柜重新识别比对、记操作日志； 第3轮仍错放则不再允许调整，按当前实况写库并记错误日志 + 操作日志。详细流程见「二、开柜调整细节流程」。
