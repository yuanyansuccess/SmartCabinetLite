# 512 维人脸特征引擎（InsightFace buffalo_l）Python 运行依赖
# 适用 Python 3.9+（开发机验证环境：Anaconda3 3.9.7）
# 安装：pip install -r requirements.txt
#
# 说明：
#   - insightface  提供 buffalo_l 套餐（SCRFD 检测 + ArcFace 512 维识别）
#   - onnxruntime  推理后端（CPUExecutionProvider；多线程由 ORT_NUM_THREADS 控制）
#   - opencv-python 图像解码（cv2.imdecode）
#   - numpy        向量运算
# 模型目录 ~/.insightface/models/buffalo_l 需包含四个文件：
#   det_10g.onnx（检测）、w600k_r50.onnx（512 维识别）、
#   2d106det.onnx（关键点）、genderage.onnx（属性）。
# w600k_r50.onnx 是输入 112x112、输出 512 维的 ArcFace 模型，
#   缺少它只能检测人脸、提不出特征。
# 离线机器请把 trunk/models/recognize.onnx 复制为 w600k_r50.onnx，
#   或用环境变量 FACE_RECOGNIZE_MODEL 指向该文件；引擎启动时按候选路径自动补齐。
insightface
onnxruntime
opencv-python
numpy
